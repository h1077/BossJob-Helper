# BossJob-Helper V1.1.2 更新日志

**日期**: 2026-07-02 | **基于**: V1.1.1

---

## 🐛 浏览器扩展修复（boss-extension）

### 岗位收集 Bug 修复
- **福利筛选从收集阶段移至筛选阶段**：原来在 `scrape()` 爬取循环中做福利关键词（如"双休"）硬过滤，BOSS 直聘列表页卡片不含福利信息导致 99% 岗位被丢弃。现已改为全量收集，在 background.js 筛选阶段再做福利匹配。
- **公司去重空字符串 Bug**：`appliedSet` 包含空字符串导致所有公司名为空的岗位被错误去重。已加 `.filter(Boolean)` 过滤 + 空公司名跳过去重检查。
- **筛选阶段新增调试日志**：打印完整筛选配置 + 各过滤器命中统计 + 被拒样本，方便排查问题。

## ✨ 桌面端新功能（boss-desktop-app）

### AI 简历解析（核心新功能）
- **新增 `POST /api/ai/parse-structured` 端点**：输入简历纯文本 → AI 解析为结构化 JSON（姓名/教育/实习/项目/技能/获奖/学生工作），遵循完整 JSON Schema，低温度 `0.2` 保证稳定性。
- **富文本保存自动触发解析**：在富文本编辑器粘贴简历 → 点击「保存到结构化编辑」→ 自动调用 AI 解析 → 自动填入结构化编辑器所有字段 → 自动回存结构化数据。

### PDF 导出升级（借鉴 VitaFlow）
- **CSS 变量驱动模板**：所有颜色/字号/边距/行高改为 CSS 自定义属性，改一行代码即可换主题。
- **分页控制**：`break-inside: avoid` + `break-after: avoid` 全量覆盖，避免标题/列表项跨页断裂。
- **模板样式设置面板**：简历管理页新增「🎨 导出样式」配置栏，可调主题色/字号/页边距/行高，配置自动保存在浏览器中。

### 结构化编辑器增强
- **可选字段显隐**：政治面貌/个人主页/通讯地址/作品集默认隐藏，有值自动显示，可按需添加/移除。
- **所有区块标题可编辑**：基本信息/教育背景/实习经历/项目经历/获奖情况/学生工作/专业技能 七个区块标题支持点击 ✏️ 重命名（如"实习经历" → "工作经历"）。
- **界面精简**：移除所有 emoji 图标，删除"籍贯"字段。
- **结构化表单高度限制移除**：编辑器不再限定 60vh 高度。

### 其他改进
- **保存按钮**：改为大号「保存到结构化编辑」，语义更明确。
- **简历列表按钮**：编辑/导出PDF/删除改为文字按钮，尺寸调大。
- **保存 URL 双重 `/api` 前缀 Bug** 修复。
- **Boss_helper.exe** 重新打包（64MB 单文件）。

## 📊 版本对比

| | V1.1.1 | V1.1.2 |
|---|---|---|
| 岗位收集 | 卡片层面福利硬过滤，收集极少 | 全量收集，筛选阶段做福利匹配 |
