## 正文（通用版，可微调适配不同平台）

### 共情开头

```
每天刷BOSS直聘，重复点"立即沟通"、复制粘贴一样的招呼语、投完就忘、
被HR已读不回……我投了半个月，回复率不到10%。

后来我花了一周写了个工具，把机械化操作全自动化了。
现在每天打开电脑放着就行，我该刷题刷题，该准备面试准备面试。
```

### 功能展示

**1. 千岗千面招呼语 — 不是复制粘贴**

```
以前："您好，我对这个岗位很感兴趣"（HR看了100条一模一样的）

现在："熟悉 React、TypeScript，做过百万PV后台重构，与贵岗位高度匹配"

每个岗位单独调AI生成，投100个岗位就是100条不同的招呼语。
投过的岗位自动缓存，不会重复消耗AI Token。

没有简历也能降级生成——AI会根据JD帮你说出对这个岗位的理解。
```

**2. AI 模拟面试 — 面试前练手**

```
选一个你想投的岗位，AI扮演HR根据真实JD问你问题。
6个阶段：开场 → 技术深挖 → 项目经验 → 综合素质 → 反问 → 结束。

面试结束自动出评估报告：
  - 综合评分（0-100）
  - 你的优势（面试中表现好的地方）
  - 待改进（回答中的薄弱点）
  - 改进建议（针对性练习方向）

历史面试记录可回看，对比进步。
```

**3. 简历评分 + AI优化**

```
上传简历 → AI从6个维度打分：
  教育背景(15分) | 技术技能(25分) | 项目经验(30分)
  职业发展(15分) | 软技能(10分) | 简历质量(5分)

AI优化严格遵守"不编造"原则：
  只优化表达方式，不添加你没做过的事
  缺数据的地方标注"📝 建议补充"，不替你编造
```

**4. 投递看板 — 不再"投完就忘"**

```
仪表盘实时显示：
  📊 今天投了多少、HR回复了多少、面试邀约了几个
  📋 投递流水表（公司/岗位/薪资/状态/时间）
  📥 一键导出 Excel / CSV / JSON

再也不会出现"这家我投没投过？""HR上次说了什么来着？"
```

**5. 完全免费 + 开源**

```
GitHub开源：github.com/h1077/BossJob-Helper
不收费、不卖会员、不割韭菜。

AI Key用你自己的：
```
